# CloudBridge — Product Steering

## Project Identity

**Name:** CloudBridge  
**Type:** Multi-Cloud Migration, Infrastructure Engineering & Cloud Security Platform  
**Owner:** Independent cloud security engineering project  
**Budget:** ₹0 — zero personal spend

## What CloudBridge Is

CloudBridge simulates a cloud consulting company that handles:

- Migration of on-premises workloads to AWS (and later Azure, GCP)
- Cloud-to-cloud migrations
- Secure cloud infrastructure design and provisioning
- Cloud security posture assessment
- Security operations and incident response
- Professional portfolio documentation

## Simulated Customers

| Customer | Profile | Scenario |
|---|---|---|
| Customer A — ACME Technologies | Ubuntu app server, PostgreSQL DB, Windows workstation, local file storage | On-premises → AWS |
| Customer B — BluePeak Solutions | Web application, DB server, Linux infrastructure | AWS → Azure |
| Customer C — NovaRetail | Existing cloud workloads | Cloud security assessment + monitoring |

All customers are fictional. Never use real customer data or credentials.

## Target Clouds

1. **AWS** — primary (current)

3. **Google Cloud Platform** — third phase

## Honesty Rules

Always clearly distinguish:
- Implemented and verified
- Tested locally (simulated)
- Deployed in cloud
- Planned / in-progress
- Demonstration data

Never present fabricated infrastructure, scan results, or metrics as real.
